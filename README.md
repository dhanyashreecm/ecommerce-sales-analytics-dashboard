# 🛒 E-Commerce Sales Analytics Dashboard

An interactive E-Commerce Sales Analytics Dashboard built using Python, Pandas, Matplotlib and Streamlit to transform transactional sales data into meaningful business insights.

https://ecommerce-sales-analytics-dashboard-x3ytmmoyvya2mcccjwwgo3.streamlit.app

## 📊 Project Overview

This project analyses e-commerce transaction data and presents the results through an interactive Streamlit dashboard.

The dashboard allows users to explore sales performance using filters for:

- Region
- Category
- Product
- Payment Method

The analysis covers revenue, orders, customers, quantity sold, product performance, regional performance, category performance and monthly sales trends.

---

## 🎯 Project Objectives

- Analyse e-commerce sales data using Python
- Build meaningful business KPIs
- Identify top-performing products and categories
- Compare regional sales performance
- Analyse monthly revenue trends
- Analyse payment-method performance
- Provide interactive filtering
- Generate automatic business insights
- Present the analysis through a web-based dashboard

## 📊 Dashboard Features

### Key Performance Indicators

The dashboard displays:

- Total Revenue
- Total Orders
- Quantity Sold
- Total Customers
- Average Order Value

### Revenue Analysis

The dashboard provides:

- Monthly Revenue Trend
- Revenue by Category
- Revenue by Region
- Product Performance
- Revenue by Payment Method

### Customer Analysis

A Top 10 Customers table displays:

- Customer ID
- Total Revenue
- Number of Orders
- Quantity Purchased

### Interactive Filters

Users can dynamically filter the dashboard using:

- Region
- Category
- Product
- Payment Method

The KPIs and insights update according to the selected filters.
